# Exact-K experimental PCM1024
The experimental runtime consumes contiguous 44.1kHz mono PCM and executes fresh acoustic + frozen S708 temporal inference once every 1024 input samples (23.21995465 ms between decisions). The frozen model was originally trained at a 1024-hop grid; its accompanying native acoustic frontend may have other training provenance, which does not change merely by changing code. No lookahead or post-attack hold is added. This is NOT the 256-sample reference branch and does not modify MIDI.
The signed FIT80 80-track scientific replay is scored at 1024; source manifest is an immutable original record named MIDI256, but *is never used as the 1024 decision clock*. Original S834 232295/306536 is historical and not framewise comparable. No claim of improved accuracy or scientific validation without completed CI metrics.
