# Baseline avant refonte causale

État figé le 28 août 2026 avant toute modification de l'architecture.

## Contrat expérimental

- GuitarSet, joueurs `00` à `04` ; joueur `05` non lu.
- Graine `1337` et split par groupes : 240 pistes d'entraînement, 60 pistes de validation.
- Audio mono PCM16 à 44,1 kHz.
- Modèle causal à 26 730 paramètres, trois sorties `onset`, `active`, `offset`, chacune sur six slots.
- 20 époques, 200 pas par époque et 50 pas de validation.

## État des tests avant correction

La commande `python -B -m unittest discover -s test` exécute 65 tests :

- 64 réussissent ;
- 1 échoue avant d'atteindre le garde-fou du joueur `05`, parce que le test
  réutilise implicitement le chemin du checkpoint existant.

Ce défaut de test sera corrigé séparément sur la branche expérimentale, sans
modifier le comportement du programme.
